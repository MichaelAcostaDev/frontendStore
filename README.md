# 🏪 Frontend Store

> **My Second Website — 2023**

This project represents the **second website I built during my early journey into web development, created in 2023**.

After building my first website and taking my first steps into programming, I wanted to continue experimenting with web development by creating something different: an online store interface.

Frontend Store was an important step in that progression because it allowed me to work with a more structured website, reusable components, product-oriented pages, and a layout designed around an e-commerce experience.

The project was later adapted to **PHP**, using reusable `include` files to organize common parts of the application.

## ☝️ About the Project

Frontend Store is a web-based e-commerce interface focused on presenting products through a simple and visually oriented storefront.

The application includes:

* A main storefront page.
* A section introducing the store.
* Product pages.
* Structured navigation between pages.
* Custom CSS styling.
* Product imagery and visual content.

The project currently represents the PHP-adapted version of the website while preserving its role as one of the earliest projects in my development journey.

## 💌 My Second Website

This project is more than an e-commerce interface in my portfolio.

It represents the **second website I created in 2023**, shortly after my first website.

At this stage of my learning process, I was beginning to understand that websites were more than individual HTML pages. I was experimenting with structure, reusable components, styling, navigation, and the way different parts of a website could work together.

Adapting the project to PHP also gave me an opportunity to start understanding server-side development and the use of reusable files through PHP `include`s.

Looking at this project today provides a clear snapshot of an early stage in my development journey.

My first website taught me how to start.

**This second website taught me how to keep building.**
